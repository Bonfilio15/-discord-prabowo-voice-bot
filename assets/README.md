# Folder Audio (`assets/`)

Taruh file audio suara khas Prabowo (**"Hey antek-antek asing!"**) di dalam folder ini dengan salah satu nama berikut:
- `antek_asing.mp3` *(Utama)*
- `antek_asing.wav`
- `antek_asing.ogg`

> **Catatan:** Jika Anda belum menaruh file `antek_asing.mp3` di folder ini saat bot pertama kali dijalankan, bot akan **otomatis membuat file suara fallback TTS (`fallback_tts.mp3`)** yang mengucapkan *"Hey! Antek antek asing!"* sehingga bot tetap langsung berfungsi. Begitu Anda menaruh file `antek_asing.mp3` asli, bot akan otomatis memprioritaskan file suara asli Anda!
